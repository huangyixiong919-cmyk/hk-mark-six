# 手机网页：特马历史数据筛选器

## 运行
- 最简单：用手机或电脑浏览器打开 `index.html`。
- 如果手机系统不允许直接打开本地 HTML，可将 `index.html` 上传到自己可用的静态网页托管服务，再用手机浏览器访问。
- 也可以在电脑上用任意静态 HTTP 服务预览，例如在该目录运行 `python -m http.server 8000`，然后在同一 Wi-Fi 下用手机访问电脑局域网地址和端口。

## 使用
1. 把核对过的历史“最后一个开奖数字”按从旧到新粘贴。
2. 设置号码范围（默认 1–49）、奇偶条件和排除号码。
3. 点击“统计并筛选 5 个号码”。
4. 查看历史出现次数、近 10/20 期次数和遗漏期数；点击复制号码。

## 说明
- 示例数据是虚构演示数据，不是真实开奖结果。
- 结果由人为设定的历史统计排序规则生成，不是预测中奖概率。
- 页面在浏览器本地计算，不会将记录上传到服务器。
